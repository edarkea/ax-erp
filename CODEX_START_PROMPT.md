# Inicio recomendado de una sesión Codex

```text
Actúa como el agente definido en AGENTS.md.

Primero identifica la fase y el módulo de esta tarea. Lee únicamente:
1. AGENTS.md;
2. docs/architecture/00-roadmap.md;
3. la especificación del módulo;
4. archivos directamente afectados.

No escanees todo el repositorio, no edites código generado y no amplíes el alcance.

Tarea:
<pegar aquí una tarea basada en tasks/PHASE_TASK_TEMPLATE.md>
```

## Regla práctica

Una sesión de Codex debe resolver una rebanada funcional pequeña, por ejemplo:

- una entidad y sus validaciones;
- un flujo transaccional;
- una vista con su servicio;
- una migración con sus pruebas.

No pedir en una sola sesión “implementar todo el ERP”.
